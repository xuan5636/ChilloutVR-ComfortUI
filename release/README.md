# CVRMG publication metadata

`rc.json` follows the supplied CVRMG Bot field layout. `_id` is `-1` for a new listing. `downloadlink` points directly to the standalone mod DLL; the EXE is linked from `description` because the supplied format has only one primary download field. `sourcelink` points to this repository.

Repository/Release publication does not submit this file to Discord or establish that the CVRMG Bot has accepted it. Submit the file through the bot's documented workflow in the intended community. No Discord credentials or chat exports are included.

`SHA256SUMS.txt` in this directory records the DLL, EXE and manual ZIP for 0.5.1. The release attachment includes all downloadable asset hashes, including the source archive and release metadata. The source ZIP cannot include its own final hash.
