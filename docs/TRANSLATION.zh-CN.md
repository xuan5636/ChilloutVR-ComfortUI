# 翻译服务设置 · 0.6.0 公开预览版

打开 **设置 → 翻译**。译文语言跟随界面语言。详情页按翻译按钮显示译文，再按恢复原文；F8 持续翻译当前及随后可见的他人气泡，再按关闭还原。每次启动默认关闭。切换服务只保存选择，不发送文本或自动下载模型。

本轮界面支持13种语言，源语言入口可展开选择自动检测或其中任一语言。在线接口使用各服务对应的语言代码；本地小模型仍可能无法可靠翻译新增语言，选项可用不代表翻译质量已通过母语审校。0.6.0完成离线桥接和回传加固检查，未重新实测在线服务的可用性。译文通过固定事件传递，以纯文本展示；格式异常、过期或目标语言不一致的结果不会替换原文。

| 服务 | 设置方法 |
| --- | --- |
| Google | 公共接口，无需密钥，可选系统／直连／手动代理；仍可能遇到公共限流。 |
| MyMemory | 公共额度，无需密钥；自动识别失败时指定源语言。 |
| Bing 免费翻译 | 使用 Bing 网页服务，不需要 Azure 密钥或区域。受网页可用性、网络和额度限制。 |
| AI 翻译 | 填兼容 Chat Completions 的服务地址、模型名称和自己的密钥；应用配置后保存密钥。远程地址要求 HTTPS，本机地址可用 HTTP。 |
| 本地模型 | 选择 CPU 兼容或优先显卡，然后点击「下载／准备本地模型」。准备完成后测试连接。 |

## 本地模型：其他电脑也能准备

使用官方 Qwen2.5-0.5B-Instruct Q4_K_M，模型491,400,032字节，CPU运行包19,662,572字节，可选Vulkan包32,307,966字节。Windows 64位；无需预装Python、Ollama或CUDA。CPU为默认，显卡模式使用兼容的Vulkan设备，不可用时改用CPU。普通游戏电脑仍需有可用内存；小模型适合短句，长文与复杂内容质量有限，本版每字段最多1200字符。

首次准备会使用当前翻译代理设置从官方模型仓库和llama.cpp发布页下载固定版本，显示进度，可取消；下载后校验SHA256，失败不启动。CPU所需初次下载合计约511MB；显卡模式再增加约32MB。安装器本身仅含模组，不内嵌大模型。升级可复用校验通过的缓存；复制其他电脑时不依赖开发电脑的路径或代理端口。

文件保存在 `UserData/ComfortUI/LocalTranslation/`，包含 `model.gguf`、固定版本运行包及解压的cpu/gpu文件夹。本地推理仅访问本机回环地址，不把聊天送到外部服务；无请求约90秒后释放进程和内存，下一次自动重新启动。运行时不会显示命令行窗口。卸载模组后模型缓存保留，用户可在游戏关闭后自行删除此专用文件夹回收空间。

0.3.1时本机 .NET Framework 独立进程已实际测试 CPU 与RTX3060的Vulkan各五条合成短句；不是完整游戏/VR或其他机器认证。CPU预热后约0.4–0.7秒，GPU约0.08–0.13秒；首次加载分别约2秒与10秒。韩语等复杂表达仍可能译错，不能据此认为小模型与大型在线服务等质。

## 代理、密钥与测试

系统、直连和手动HTTP代理仅作用于本模组，不改Windows设置。手动地址示例 `http://127.0.0.1:7890`，端口以实际代理软件为准。本地模型的文件下载遵循此选择，推理始终直接访问回环地址。

仅AI服务显示密钥框。密钥经Windows当前用户加密，独立存放于 `translation-credentials.dat`，绑定AI服务地址；保存后输入框清空，不进入偏好、网页缓存或日志。旧Azure/Libre密钥保留在原加密文件中但不被新Bing/本地服务读取或发送，升级不把它们上传到别的服务。

「测试翻译连接」始终用合成短句实际请求，不把缓存命中当成连接成功；限流冷却仍生效。错误显示在页面上。0.3.1独立测试中Bing经本机代理五个目标语言HTTP200；Google之前的公共429仍未解除，本版没有再次测试Google。在线服务可能不可用，失败保留原文，不自动跨服务上传。
